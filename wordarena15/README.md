# WordArena 15

A premium 15-tile word-strategy and vocabulary-learning game prototype by BillionPrompts.ai.

## Run
Open `index.html` in a modern browser or serve this folder as static files. No build step is required.

## V1 features
- Responsive 15×15 board and 15-tile rack
- Tile placement, recall, shuffle, exchange, pass, basic scoring and bonus squares
- Human vs AI shell and AI turn engine
- AI-vs-AI Demo Arena presentation
- Difficulty and risk dashboard gauges
- Free Dictionary API discovery with graceful offline fallback
- Learning word list stored locally
- Local leaderboard/personal best
- Printable/PDF certificate and email handoff
- Static-hosting friendly architecture

## Important
WordArena 15 is an independent game variant. It does not claim official Scrabble® rules or tournament compatibility. V1 is an engineering prototype: cross-word validation, sophisticated AI search, complete competitive lexicon, true network multiplayer, server leaderboard, and transactional certificate email are planned upgrades.
